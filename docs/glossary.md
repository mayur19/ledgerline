# Glossary

Domain terms as used in Ledgerline's code, API and documentation.

| Term                                        | Definition                                                                                                                                                           |
| ------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Account**                                 | A ledger bucket in an entity's chart of accounts, identified by a code (e.g. `6300`) and typed as asset, liability, equity, revenue or expense.                      |
| **Account type**                            | One of five classes that decide the normal side and whether the balance carries forward (balance sheet) or resets each fiscal year (income statement).               |
| **Accounting period**                       | A date range (normally a calendar month) within a fiscal year whose status controls posting: `open`, `soft_closed` or `closed`.                                      |
| **Apportionment (largest remainder)**       | Splitting a rounded total across lines in proportion to their amounts so the parts sum exactly to the total; leftover units go to the largest fractional remainders. |
| **Approver**                                | Role that can approve submitted entries but never create them (segregation of duties).                                                                               |
| **Audit event**                             | Append-only record of a state change (actor, action, target, metadata, request id), written in the same transaction as the change.                                   |
| **Auditor**                                 | Read-only role with access to journals, reports and the audit trail.                                                                                                 |
| **Balance sheet account**                   | Asset, liability or equity account; its balance carries forward across fiscal years.                                                                                 |
| **Banker's rounding (half-even)**           | Rounding exact halves to the nearest even digit (0.275 → 0.28, 0.385 → 0.38) to avoid systematic upward bias.                                                        |
| **Chart of accounts**                       | The hierarchical list of accounts for one entity; header accounts group postable children.                                                                           |
| **Closed period**                           | Period that accepts no postings from anyone; enforced by the application and a commit-time database trigger.                                                         |
| **Closing balance**                         | Opening balance plus period debits minus period credits (debit positive).                                                                                            |
| **Consolidation**                           | Combining the ledgers of entities in a group into one set of figures, removing intra-group balances (planned, M5).                                                   |
| **Controller**                              | Role responsible for close: manages periods, accounts and rates and may post into soft-closed periods.                                                               |
| **CSRF token**                              | Random value set in the readable `ll_csrf` cookie and echoed in the `X-CSRF-Token` header; must match the hash bound to the session.                                 |
| **CTA (cumulative translation adjustment)** | Equity line absorbing differences from translating a subsidiary at different rates (planned, LL-055).                                                                |
| **Debit / credit**                          | The two sides of every journal line; an entry balances when total debits equal total credits in functional currency.                                                 |
| **Distinct-email cap**                      | Limit on how many different emails one normalised IP may try per window, preventing store flooding and spraying.                                                     |
| **Draft**                                   | A validated journal entry without a number; becomes posted after re-validation.                                                                                      |
| **Due-to / due-from**                       | Intercompany payable and receivable accounts that must offset on consolidation.                                                                                      |
| **Elimination**                             | Consolidation adjustment removing intercompany balances and transactions (planned, LL-063).                                                                          |
| **Entity (legal entity)**                   | A company in the group with its own chart, periods, functional currency and time zone.                                                                               |
| **Entry number**                            | Gapless reference `ENTITY-FY-NNNNNN` assigned at posting, e.g. `NW-US-2026-000007`.                                                                                  |
| **Exchange rate**                           | Units of one currency per unit of another for a date and rate type; stored with 10 decimals and used as an exact rational.                                           |
| **Fiscal year**                             | Twelve (or thirteen) consecutive periods labelled by the calendar year in which they end (FY2028 for Jul 2027–Jun 2028).                                             |
| **Functional currency**                     | The currency an entity keeps its books in; every line is converted to it.                                                                                            |
| **FX rounding account**                     | Entity-configured account that receives sub-unit residues from cross-currency entries.                                                                               |
| **Gapless numbering**                       | Sequence with no holes or duplicates per entity and fiscal year, guaranteed by a row-locked counter in the posting transaction.                                      |
| **Header account**                          | Non-postable summary account whose trial balance figures are the roll-up of its descendants.                                                                         |
| **Idempotency key**                         | Client-supplied header that makes journal creation safe to retry; the same key returns the original entry.                                                           |
| **Income statement account**                | Revenue or expense account; resets at fiscal-year start, with prior-year net moving to retained earnings.                                                            |
| **Intercompany transaction**                | A transaction between two entities of the same group, recorded as mirrored entries (planned, LL-060).                                                                |
| **Journal entry**                           | A dated, balanced set of two or more lines with memo and optional reference.                                                                                         |
| **Journal line**                            | One debit or credit of an amount in a currency to an account, with its rate and functional amount.                                                                   |
| **Minor units**                             | Integer representation of money in the currency's smallest unit (cents for USD, yen for JPY, fils for KWD).                                                          |
| **Monetary account**                        | Account settled in a fixed amount of currency (cash, receivables, payables) and therefore revalued at period end.                                                    |
| **Non-controlling interest (NCI)**          | The share of a partly owned subsidiary's equity and profit belonging to outside shareholders (planned, LL-064).                                                      |
| **Normal side**                             | The side on which an account type usually carries its balance: debit for assets/expenses, credit for liabilities/equity/revenue.                                     |
| **Opening balance**                         | Balance at the start of the report range: all prior activity for balance sheet accounts; fiscal-year-to-date activity for income statement accounts.                 |
| **Organization**                            | The tenant: a customer's group of entities, users and rates. All data is scoped to one organization.                                                                 |
| **Posting**                                 | The irreversible transition of an entry from draft to posted, assigning its number and making it immutable.                                                          |
| **Posting engine**                          | Pure function (`prepareEntry`) that validates lines, resolves rates, converts amounts and decides balance.                                                           |
| **Progressive backoff**                     | Lockout whose duration doubles with each consecutive failed login past a free budget, capped at one hour.                                                            |
| **Rate type**                               | `spot` (posting), `average` (P&L translation) or `closing` (revaluation and balance sheet translation).                                                              |
| **Reconciliation**                          | Matching bank statement lines to ledger lines and explaining differences (planned, M6).                                                                              |
| **Retained earnings**                       | Equity account accumulating prior years' profit or loss; the trial balance rolls prior-year P&L into it.                                                             |
| **Revaluation**                             | Re-measuring foreign-currency monetary balances at the closing rate and posting unrealized gain/loss (planned, LL-052).                                              |
| **Reversal**                                | A new entry with swapped sides that cancels a posted entry, linked to it (planned, LL-035).                                                                          |
| **Rounding residue**                        | The difference left when several foreign sides are rounded independently; at most ⌊k/2⌋ minor units for k rounded sides.                                             |
| **Segregation of duties (SoD)**             | Control ensuring no single person can both prepare and approve the same transaction.                                                                                 |
| **Soft-closed period**                      | Period open only to users with `journal.post_soft_closed` (controllers) for late adjustments.                                                                        |
| **Translation**                             | Restating a subsidiary's figures in the group presentation currency (planned, LL-055).                                                                               |
| **Trial balance**                           | Report of every account's opening, period and closing balance whose debit and credit totals must agree.                                                              |
| **TRUST_PROXY**                             | Configuration naming which reverse proxies may set client IP headers: `false`, a hop count or an IP/CIDR list.                                                       |
| **Unrealized gain/loss**                    | FX difference on balances not yet settled, recognised by revaluation.                                                                                                |
